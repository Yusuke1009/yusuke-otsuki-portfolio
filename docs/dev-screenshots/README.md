# Dev Screenshots

UI開発中に撮影した進行履歴のスクリーンショット置き場。
最新の見た目を確認したいときは `npm run dev` を起動して直接ブラウザで見ること。

## 命名規則

- `home-vN.png` … トップページ Nバージョン目
- `home-vN-hero.png` … ヒーローセクションのみ
- `home-vN-full.png` … フルページ
- `about-vN.png` / `resume-vN.png` / `work.png` / `digikar-vN.png` … 各ページ
- `tour-*.png` … 全ページを順に巡って撮ったスクリーンショット一式
- `portfolio-home.png` … MCP Playwright から自動で撮ったもの

## ファイル追加ルール

- 新規スクショは必ずこのディレクトリに保存する（ルートに置かない）
- 不要になった古いバージョンは削除してよい（git履歴に残るため）
