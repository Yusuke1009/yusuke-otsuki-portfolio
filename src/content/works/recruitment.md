## Overview

戦略立案から PR、面接・面談、意思決定まで一気通貫。デザイナーは2年で9名採用（例年比 +4 ペース）。エンジニア採用 PR や事業採用も支援。

## Phase 01

- Label: 戦略立案と PR実行
- Period: 2022 — 
- Headline: 採用 LP、SNS、Designship ノベルティで PR の総合戦略を組む

採用戦略の立案から SNS 運用、Designship ノベルティ企画 PJ リード、エンジニア採用ノベルティ関連の企画・デザインまで。複数チャネルを束ねて PR の総合戦略として実行。

### Achievements

- 採用戦略の立案と実行
- 限られた予算でキャッチーなノベルティを開発し採用 PR インパクトを創出
- SNS、動画 PR で PR 効果の最大化
- デザイナー採用 LP / 動画チーム採用 LP のデザイン
